# ReyCloud IG Review

**Instagram Account Review Tool**

[![Vercel](https://img.shields.io/badge/Deploy-Vercel-black?logo=vercel)](https://vercel.com/)
[![Node.js](https://img.shields.io/badge/Node.js-22%2B-green?logo=node.js)](https://nodejs.org/)
[![License](https://img.shields.io/badge/License-MIT-blue)](LICENSE)

</div>

## ✨ Features

- 📱 Custom device picker
- 🤖 Android
-  iPhone / iOS
- 🌐 Web / Browser
- 🔒 Account Disabled
- ⛔ Account Suspended
- 🔑 Login Issue
- 💬 Other Account Issue
- 📷 Upload foto atau screenshot kejadian
- 🖼️ Preview foto
- 📋 Copy teks permohonan
- 📧 Buka aplikasi email pengguna
- 📎 Panduan lampiran foto
- 📱 Responsive UI
- ⚡ Vercel Serverless API
- 🔐 Foto tidak di-upload ke server

## 🚀 Installation

git clone https://github.com/USERNAME/REPOSITORY.git
cd REPOSITORY
npm install

## 💻 Local Development

npm install -g vercel
vercel dev

## ☁️ Deploy to Vercel

vercel login
vercel

Production:

vercel --prod

## 📧 Email Review

Tombol "Kirim via Email" membuka aplikasi email pengguna menggunakan mailto:.

Alamat tujuan yang dikonfigurasi:

instagram-android@meta.com

Setelah email terbuka:

1. Jangan tekan "Send" terlebih dahulu.
2. Klik ikon "📎 Lampiran".
3. Pilih foto atau screenshot kejadian.
4. Pastikan foto sudah terlampir.
5. Periksa kembali isi email.
6. Tekan "Send".

## 📷 Evidence

Foto yang dipilih hanya digunakan untuk preview di browser.

Foto tidak dikirim ke API dan tidak disimpan oleh project.

Format yang didukung:

JPG
JPEG
PNG
WEBP

Ukuran maksimum:

5 MB

## 🔐 Privacy

Project ini tidak membutuhkan:

- Password Instagram
- Cookie Instagram
- Session Instagram
- Access Token
- SMTP Password

Jangan meminta pengguna memasukkan password Instagram ke tools.

## ⚠️ Disclaimer

ReyCloud IG Review bukan aplikasi resmi Instagram atau Meta.

Tools ini hanya membantu membuat draft permohonan tinjauan dan membuka aplikasi email pengguna.

Pengguna bertanggung jawab atas informasi yang dikirimkan.

Alamat email tujuan juga sebaiknya diverifikasi terlebih dahulu sebelum digunakan sebagai kanal dukungan resmi.
